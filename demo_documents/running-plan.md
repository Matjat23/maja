# Sample 5 km running plan

- Weeks 1-2: run 1 minute, walk 2 minutes, repeat 8 times. Three sessions per week.
- Weeks 3-4: run 3 minutes, walk 1 minute, repeat 6 times.
- Weeks 5-6: run 10 minutes without stopping, twice per session.

Always warm up for 5 minutes and stretch your calves and hamstrings afterwards.
